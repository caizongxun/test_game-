# 3D 皇家小豬牧場 (3D Royal Pig Ranch) 🐾✨

> 高精細公仔物理養成、1,023 種料理配方合成模擬，以及支援 Supabase 雲端多人在線協同養成與伺服器端權威金幣同步的小遊戲。

---

## 🌟 核心特色與優化項目

### 1. 🤝 房間代碼與多人在線協同共養 (Multiplayer Pet Co-op)
- **房間代碼系統**：每個寵物房間皆具備專屬代碼（如 `PIG-8821`），並支援邀請連結分享（`?room=PIG-8821`），朋友點擊連結即可直接進入同一個牧場。
- **即時在線 Presence 廣播**：透過 Supabase Realtime 即時感知線上好友狀態（顯示在線人數與夥伴暱稱）。
- **同步協同養成**：
  - 當好友投餵食材、料理，小豬會在雙方螢幕上同步享用並長肉。
  - 當好友撫摸小豬、更換頭飾裝扮、購買新玩具時，雙方畫面毫秒級同步顯示動態反饋。
- **即時動態牆 (Live Activity Feed)**：記錄誰撫摸了小豬、投餵了哪道料理、賺取或消耗了多少金幣。
- **離線單機無縫降級**：在未設定 Supabase 金鑰前，遊戲自動以單機模擬模式順暢運行，不會報錯或中斷體驗。

### 2. 💰 伺服器端權威計算與金幣安全同步 (Server-Authoritative Economy)
- **雲端資料庫儲存**：寵物所有數值（金幣、體重、飽足、心情、活力、清潔、親密度、解鎖食譜、道具與升級等級）皆由 Supabase PostgreSQL 託管。
- **防雙花與 Race Condition 保護**：
  - 核心函數 `apply_pet_action` 採用 `FOR UPDATE` 行級排他鎖，確保雙方同時點擊或購買時金幣不會出錯或變成負數。
- **防作弊被動掛機計算**：
  - 透過伺服器端預存程序 `sync_idle_income`，根據真實伺服器時間差計算掛機收益，防範修改客戶端本機時間。

### 3. 🎨 3D 模型高精細化與擬真公仔渲染 (Refined 3D Visuals)
- **高密度軟體形變網格**：將小豬基礎網格頂點細分大幅提升（SphereGeometry 92 × 64），使軟體揉捏、拖曳、戳動更加圓潤細膩。
- **頂級設計師公仔質感材質 (MeshPhysicalMaterial)**：
  - 加入細緻的 `Clearcoat`（清漆透明塗層）、`Sheen`（微細絨毛次表面散射光）與柔和的 `Roughness`，呈現類似高級軟膠潮玩公仔的溫潤觸感。
- **立體精緻細節**：
  - **水潤光澤豬鼻**：新增獨立高光微反射鼻吻結構與呼吸微動嗅探動態。
  - **生動五官與眉毛**：新增立體眉毛與多點晶瑩眼神光，開心時瞇眼微笑、睡覺時閉合雙眼。
  - **粉嫩蹄墊**：在深色豬蹄下方新增雙色粉嫩腳墊，奔跑與跳躍時清晰可見。
  - **動態物理捲尾**：根據開心度與走動速度產生程序化擺動效果。
- **攝影棚級輪廓光 (Rim Light)**：
  - 新增側後方粉調輪廓邊緣光，勾勒出小豬圓滾滾的輪廓立體感。
- **全新潮流與神聖飾品**：
  - 嫩綠豆苗、皇家主廚帽、田園草帽、純金皇冠、暖陽紅圍巾。
  - **新增**：神聖天使光環與羽翼 (`angel`)、潮流酷炫黑超墨鏡 (`glasses`)、皇家領結純金鈴鐺 (`bell`)、魔幻星宿大巫師帽 (`wizard`)。

## 🚀 部署至 GitHub Pages 教學

本專案採用純靜態前端架構，可直接免費託管於 GitHub Pages：

1. **推送代碼至 GitHub 倉庫**：
   確保 `index.html`、`supabase-config.js`、`supabase-service.js` 位於倉庫根目錄。
2. **開啟 GitHub Pages**：
   - 進入您的 GitHub 倉庫頁面：`https://github.com/caizongxun/test_game-`
   - 點擊頂部選單的 **Settings**（設定）。
   - 在左側側邊欄點擊 **Pages**。
   - 在 **Build and deployment** > **Branch** 下方：
     - 分支選擇：`main`
     - 目錄選擇：`/(root)`
     - 點擊 **Save**。
3. **完成上線**：
   數十秒後即可透過以下網址遊玩並分享：
   `https://caizongxun.github.io/test_game-/`

## 🛠️ Supabase 後端設定教學 (只需 2 分鐘)

若要啟用跨裝置多人即時連線與伺服器端金幣同步：

### 步驟 1：建立 Supabase 專案
1. 前往 [Supabase 官網 (https://supabase.com)](https://supabase.com) 免費註冊並登入。
2. 點擊 **New project** 建立新專案（例如名稱設為 `pig-ranch-backend`）。

### 步驟 2：執行資料庫 SQL 腳本
1. 在 Supabase 左側選單進入 **SQL Editor**。
2. 點擊 **New query**。
3. 打開本專案的 [`supabase_schema.sql`](supabase_schema.sql)，複製全文貼上至 SQL Editor 中。
4. 點擊右下角的 **Run** 執行（將自動建立 `pets` 與 `pet_actions` 表格、RPC 交易函數、安全政策與 Realtime 廣播）。

### 步驟 3：獲取連線金鑰並填入遊戲
1. 在 Supabase 左側點擊 **Project Settings** > **API**。
2. 複製以下兩項資訊：
   - **Project URL**（專案網址，例如：`https://xxxxxx.supabase.co`）
   - **anon public Key**（公開匿名金鑰，例如：`eyJhbGciOi...`）
3. **填入方式（二選一）**：
   - **方式 A（免改代碼）**：進入遊戲後，點擊右上角「共養代碼」>「展開/收起金鑰配置」，貼上後點擊「保存設定並連線」。
   - **方式 B（寫死在專案中）**：打開專案中的 `supabase-config.js`，填入 `DEFAULT_SUPABASE_CONFIG` 中並提交推送。

## 🎮 操作指南

| 動作 | 操作方式 |
| :--- | :--- |
| **撫摸小豬** | 在小豬身上持續滑動（PC 滑鼠指針滑過 / 手機單指滑過） |
| **戳弄/輕拍** | 單擊小豬身體任意部位 |
| **抓起小豬搬運** | 長按小豬身體約 0.3 秒，待粉紅集氣環滿後拖曳，可移動至進食區、睡眠屋、溫泉沐浴桶、遊樂區 |
| **投餵食材** | 點擊下方食材或木架上的食材投入食槽，合成 1,023 道料理之一後點擊「立即開動」 |
| **旋轉/縮放視角** | 滑鼠右鍵或空白區域左鍵拖曳旋轉，滾輪縮放；手機雙指捏合縮放 |
| **多人共養** | 點擊右上角「共養代碼」，複製代碼或專屬邀請網址發送給好友 |
